First run

Install and verify

Try editing Gullwing in your browser or play the original demo with no install. To author your own game from source, install Node.js 22.18 or newer and Git. Open PowerShell, Command Prompt, or your macOS or Linux terminal in the folder where you want Emaki.

node --version
npm --version
git --version
git clone https://github.com/AbhishekNair050/Emaki.git
cd Emaki
npm install
npm run check

A successful check prints ✓ No problems found, followed by counts for labels, dialogue and menus.

Version checks
Confirm the three tools are available. On PowerShell, use npm.cmd in place of npm if script execution blocks npm.ps1.
Clone and install
git clone downloads the engine, cd Emaki enters its folder, and npm install installs its dependencies.
Check the sample
npm run check compiles the bundled story and reports any problems before you launch anything.
Windows desktop installation

On Windows x64, download the Emaki Studio installer from GitHub Releases. The installer is unsigned, so Windows may show a SmartScreen warning. Open Studio from the Start menu after installation. It includes its own Node runtime. Install FFmpeg separately for optional sound, voice, and movie compression.

On macOS and Linux, use the source setup above.

Start Emaki

npm run launch

The project launcher normally opens at http://127.0.0.1:5175/. Keep its terminal open while using the editor and player. npm run studio opens the same launcher in a desktop window from the source checkout. npm run dev starts the bundled game directly.

Set up your first project

  1. Choose New project. Game title is what players see. Location is the parent folder. Project folder is the new directory inside it. Use Browse… to pick the location, check the full path under the fields, and click Create project.
  2. Open Write. Play the starter story once and edit a line of dialogue to see the preview update.
  3. Add a background, sprite, or audio file on the Assets tab, then drag the asset into the script to declare and use it.
npm run emaki -- new ../my-game --title "My Game"
npm run emaki -- edit ../my-game
npm run emaki -- play ../my-game
story.vn
The main script. It contains the game header, declarations, and scenes. Keep it in the project's root.
theme.css
The place to change the look of menus, dialogue, and other screens.
assets/
Put images, music, sound, and other media here. Paths in your script are relative to this folder.
Import from Ren’Py…
Choose the existing project folder that contains game/. Emaki creates a new project and writes an import-report.md listing items that need attention. Read the conversion coverage.
Open an existing Emaki project

Click Open…, enter the folder containing story.vn or locate it using Browse…, then open the project and choose a workspace.

Import an existing Ren’Py project

Use a project with editable .rpy source files. Set a separate destination folder and select Import project. Open the result, review import-report.md, then play through the routes you depend on. Custom Python, screens, and animations can require manual work.

Build your first playable scene

Create a fresh project called The Lighthouse Door and keep its starter assets/bg/sky.svg. Replace the contents of that project's story.vn with this complete script.

---
title: The Lighthouse Door
start: arrival
---

define ava "Ava"
image sky = "bg/sky.svg"

label arrival:
  scene sky with fade
  ava: The lighthouse is just ahead.
  menu:
    "Knock on the door.":
      jump knock
    "Keep walking.":
      jump walk

label knock:
  ava: Come in. The kettle's on.
  end

label walk:
  "The light sweeps across the empty path."
  end
  1. Open the editor and choose Write. Put the cursor on ava: The lighthouse is just ahead. and press Ctrl+Enter.
  2. Advance to the menu and pick Knock on the door. Ava should invite you in. Play from the same line again and pick Keep walking. to see the other branch.
  3. Change The kettle's on. to your own dialogue. Play that line again to confirm the edit. Then open Story and check that arrival leads to both knock and walk.

The header picks the entry label, define registers a speaker, and image names an asset. Each jump sends the selected branch to another label. end finishes that path.

Write with the game running

Scenes and Assets
Scenes jumps to each label. Assets lists existing media and accepts file drops from your computer. Drop an asset into the script to insert its declaration and a matching story command.
File picker and New file
Switch between scripts or add a file for another chapter or route.
Play from cursor, previous and next, Restart
Ctrl+Enter plays from the current line. The arrows move between lines. Restart returns the preview to the title screen.
Format, Problems, and save status
Format tidies layout. Problems opens diagnostics. Emaki saves edits as you type and shows the last working version in the preview while you fix an error.
Lines and Inspector
The bottom tracks show dialogue, choices, sprites, scenery and audio at each point. The Inspector shows the selected line and its state, and can edit supported properties.
Add assets and split the script

Open Assets and drop a file from your computer onto the list. The editor copies it into the project. Drag an image or audio item from the list onto your script to declare and use it. Give character images an expression name if you want the speaker's portrait to change with dialogue.

Use New file to add a chapter or route file, and the file picker to switch between it and story.vn. Keep the main header in story.vn.

What the script does

var trust = 0

label arrival:
  scene cliff_road with fade
  show mira neutral at center with dissolve
  mira: You're early.
  menu:
    "I wanted to see the light come on.":
      set trust += 1
      mira smile: Did you now.
    "The driver wanted to beat the storm.":
      mira: Smart man.

This excerpt assumes the character, background and sprites have already been declared. A label names a scene. scene sets a background, show places a sprite, a speaker followed by a colon speaks, and menu offers choices. set changes a value that later conditions can read. A quoted line by itself is narration.

Follow a route through the story

Route to · Search again
Find a path to each reachable ending. Selecting a route highlights its scenes and sets the variables used by preview when you play from a line.
Flowchart
Pan and zoom to inspect the branching story. Click a scene to select it, or double-click to play it. Add and rename scenes or connect them to create jumps and choices.
Color views and Inspector
Color scenes by playtest coverage, word count, or a variable. The Inspector shows scene counts, state, and the route's choice. Open the scene in Stage or in the script.

Get to know the player

Try the browser editorPlay Gullwing PointPlay the plugin demo
Start · Load · Extras · Settings
Begin the story, resume from a saved slot, see unlocked content, or change reading and playback preferences. Load appears on the title screen when a save exists.
Advance and choose
Click or tap to reveal or advance dialogue, or use Enter or Space. Pick a response when a choice appears.
Back · Log
Back rolls back one line. Log opens the dialogue history. Select an earlier line to roll back to it. Voiced games can offer replay from the backlog.
Save · Load · Menu
Save stores a position with a thumbnail. Load resumes a slot. Menu opens the game's custom menu if it has one, or asks before returning to the title.
Auto · Skip · Next choice
Advance at a reading pace, skip eligible text, or advance to the next choice. By default, normal skipping stops on unread lines.
Extras
View unlocked replays, music, endings, achievements, and any gallery images the game declares.
Choices, keyboard controls, and Extras

In the default player, Enter, Space, Page Down, and right arrow advance. Page Up and left arrow roll back. Use A for Auto, S for Skip, L for Log, H to hide or show the interface, and O for Settings.

Player settings

Full screen · Text speed · Auto-advance wait
Change display mode, how quickly letters appear, and how long Auto waits ahead of the next line.
Master · Music · Sound · Voice
Master sets overall volume. Use the other sliders to balance the music, sounds and spoken dialogue separately.
Text size · Text box opacity · Font
Adjust readability and check the sample text below the controls. The player includes Atkinson Hyperlegible and OpenDyslexic options.
Skip · Animations · Language
Choose whether Skip can pass unread text, and whether animation follows device preferences or uses reduced motion. The language picker appears for translated games.
Reset to defaults · Done
Restore the starting preferences or return to the game.

Customize and extend

Production features
Use layered sprites for outfits, side portraits for speakers, camera moves and transitions for staging, NVL for full-page text, and movies for cutscenes.
Screen and theme
Set the title art in the header or use a screen block for custom menus, dialogue, settings, saves, history, confirmations, and Extras. Style them with theme.css.
Translation and voice
Generate translation catalogs with strings and a recording sheet with voices. Keep translated text in PO or CSV and use language-specific media where required.
Plugins
Add commands, expression functions, and screen elements. The plugin demo shows a weather effect, a memory minigame, and a screen meter.
Give the starter game a title screen

Add these lines inside the header of The Lighthouse Door, restart the preview, and check that the starter sky fills the title screen and the title menu sits on the left.

title_image: bg/sky.svg
title_layout: left
title_buttons: start, settings

A label title: lets the title screen play like a scene. Use screen title: for custom layout and buttons. Use theme.css to style the screens and dialogue box.

Translate a line and prepare voice recordings
  1. Run npm run emaki -- strings ../my-game/story.vn --lang fr --csv. Open lang/fr.csv in the project and enter a French translation for one line in the translation column.
  2. Launch the game, select French in Settings, and play that line. Missing or unreviewed translations use the original text. Rerun the command after changing the script to update the catalog.
  3. To prepare recordings, set voice: voice/{speaker}/{id}.ogg in the header and run npm run emaki -- voices ../my-game/story.vn. The generated voice-script.csv lists each recording's expected path under assets/.

Use VS Code and the dev server

Install the VS Code extension from source

npm run build:vscode
npm run package -w emaki-vscode

In VS Code, run Extensions: Install from VSIX… and select the generated .vsix in packages/vscode/. Open your game's folder to get highlighting, diagnostics, completion, hover information, and navigation for .vn files. F12 goes to a definition. Shift+F12 lists references.

Preview with any text editor

npm run emaki -- play ../my-game --no-open

Open the printed URL. Emaki reloads the game as you save the script. Press M to toggle the dev story map and click a scene to jump to it. To preview a specific state, append ?line=52&trust=2 to the demo's dev URL. Add &file=chapters/two.vn when selecting a line in a different file. In VS Code, Ctrl+Alt+Enter sends the cursor line to the configured dev server.

Script features by task
Organize a long story
Use a header for project settings, declarations for reusable names, and labels for scenes. Split chapters into separate files and jump or branch between labels.
Compose a shot
Declare backgrounds and sprite expressions, then use transitions, positions, moves, camera effects, free image layers, or color tones. Name a side image for a portrait in the dialogue box.
Set the reading rhythm
Use text styling, ruby annotations, inline pauses, or NVL pages. Music, ambience, and effects play on their own channels. A movie can take over the stage for a cutscene.
Track decisions
Store decisions in variables, test them in conditions, and jump to scenes or endings. Declare achievements, music, and replays so they can appear in Extras.
Command-line examples 
npm run emaki -- check ../my-game/story.vn
npm run emaki -- fmt ../my-game/story.vn --write
npm run emaki -- graph ../my-game/story.vn
npm run emaki -- build ../my-game/story.vn
npm run emaki -- strings ../my-game/story.vn --lang fr
npm run emaki -- voices ../my-game/story.vn
npm run emaki -- plugin ../my-game weather --ts

These commands report script errors, format source, print a Mermaid graph, compile the story, generate a French catalog, prepare a recording sheet, and scaffold a TypeScript plugin, respectively.

Export and publish

In the launcher, select a game and an export target. The export log shows where the build went. For a browser game, use the launcher’s Web export or run this from the engine checkout.

npm run export -- web ../my-game
Web
Host the contents of export/web/ as a website or zip its contents for an itch.io HTML game. Browser saves are kept in that browser.
Desktop and Steam
Windows x64 has a WebView2 export. Electron targets Windows, macOS, and Linux with optional Steam support. Consult the target guide for packaging, signing and testing.
Android and iOS
Export a Capacitor project for Android Studio or Xcode. Android builds require the Android SDK and Java 21 or newer. Building for iOS requires a Mac with Xcode. See the export reference for debug builds and store packaging.
Compression
Adjust image format and resizing, sound and voice compression, and movie compression per project. Check the size estimates and play the exported game before sharing it.

When something goes wrong

Version or command errors
Check the Node version, restart the terminal after installation, and run commands from the Emaki checkout that contains package.json.
The launcher tab did not open
Use the exact local address printed in the terminal. To choose another port and print the URL without opening the browser, use npm run launch -- --port 5180 --no-open.
Your folder does not open
Choose the folder that directly contains story.vn. Quote paths containing spaces on the command line.
A scene stopped updating
Open Problems and fix the first file and line it lists. From the terminal, run npm run emaki -- check ../my-game/story.vn.
Missing art or sound
Check the file name and capitalization under assets/, and check the declaration and command referring to it.
